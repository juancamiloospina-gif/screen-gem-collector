# Rediseño integral AssisPrex

## Objetivo
Convertir el prototipo actual en una experiencia moderna de centro operativo, usando la identidad azul de AssisPrex y conservando todos los datos y flujos funcionales.

## Recorrido
1. Crear una pantalla inicial clara para entrar como Director de Flota o reportar una asistencia.
2. Llevar al usuario al centro operativo con navegación lateral, buscador, indicadores y alertas en vivo.
3. Reemplazar la silueta abstracta por un mapa reconocible de Colombia, con regiones, ciudades y casos clicables.
4. Conectar cada caso con una vista de detalle moderna que muestre datos, SLA y las ocho etapas.
5. Aplicar el mismo lenguaje visual a Reportar incidente, Alertas y Antes / Después.

## Diseño
- Paleta AssisPrex: `#07165C`, `#163F9F`, `#55A7D9`, `#F4FAFD`.
- Tipografías Sora para títulos y Manrope para interfaz.
- Centro operativo oscuro y limpio, con azul como identidad; verde, ámbar y rojo solo para SLA.
- Navegación lateral, superficies compactas, iconografía funcional y movimiento discreto.
- Adaptación para escritorio y móvil sin perder legibilidad ni acceso a acciones.

## Alcance técnico
- Mantener la base de datos y las consultas existentes.
- Reorganizar la envoltura, navegación y pantallas actuales.
- Construir el mapa como una representación geográfica detallada de Colombia dentro del proyecto, sin depender de una conexión externa.
- Añadir el nuevo inicio y conservar el chat simulado, las alertas y la comparación operativa.
- Verificar el recorrido completo en navegador y corregir solapamientos o errores visuales.
